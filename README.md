# Job Matcher

An AI job-matching backend: semantic search over job listings plus an LLM agent that recommends the best matches.

## Features
- Semantic job search using sentence-transformers embeddings and FAISS
- LLM agent with tool calling (the model decides when to search jobs)
- FastAPI endpoints: /search and /match

## Tech stack
Python, FastAPI, FAISS, sentence-transformers, NVIDIA-hosted LLM (OpenAI-compatible API)

## Run locally
    pip install -r requirements.txt
    set NVIDIA_API_KEY in your environment
    uvicorn main:app --reload
Then open http://127.0.0.1:8000/docs

## Note
The dataset is synthetic sample data generated by make_jobs.py.
